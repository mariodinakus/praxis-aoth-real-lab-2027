# PRAXIS — AOTH ECON LAB 2027

Ανεξάρτητο διαδραστικό εκπαιδευτικό dashboard για τα Κεφάλαια 1–2 της Οικονομίας / ΑΟΘ Πανελλαδικών 2027.

## Εκτέλεση και περιεχόμενο
- Στατικό HTML, CSS και JavaScript στο `public/index.html`, χωρίς εγκατάσταση εξαρτήσεων.
- Εργαστήριο ΚΠΔ και κόστους ευκαιρίας, εργαστήριο ζήτησης, ελαστικότητας και συνολικής δαπάνης.
- Πραγματικές αναφορές της ΕΛΣΤΑΤ και Eurostat με ημερομηνίες και συνδέσμους πηγών.
- Οκτώ ερωτήματα αυτοελέγχου, λειτουργία καθηγητή και τυπολόγιο.
- Οι καμπύλες και οι ποσότητες των διαδραστικών υποδειγμάτων είναι υποθετικές.

## Ανάπτυξη στο Render
Static Site από αυτό το GitHub repository (`main`).
Build Command: `echo 'Static site ready'`
Publish Directory: `public`
Ενεργοποίηση Auto Deploy: `yes`.

Το αρχείο `render.yaml` αποτελεί εναλλακτική περιγραφή υποδομής.
Δεν απαιτούνται API keys ή environment variables.
